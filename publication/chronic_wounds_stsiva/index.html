Two-step Deep Learning Framework for Chronic Wounds Detection and Segmentation: A Case Study in Colombia

Brayan Monroy, Jorge Bacca, Karen Sanchez, Henry Arguello, Sergio Castillo
October 2021
PDF Source Document DOI

Abstract

Chronic wounds represent a major healthcare challenge. This study introduces a two-step deep learning framework for automated wound detection and precise boundary segmentation, validated on an annotated clinical dataset in Colombia, delivering significant diagnostic efficiency.
